# Practical 1: Exploring Deep Learning Libraries and Basic Tensor Operations Using TensorFlow

## Aim
To familiarize students with popular deep learning libraries and perform basic tensor creation and mathematical operations using TensorFlow.

## Data Source
Not Applicable (synthetic tensor operations and matrix computations).

## Project Results & Insights
* Verified TensorFlow and NumPy environments with successful eager execution.
* Constructed tensors across ranks 0 through 3 (`scalar`, `vector`, `matrix`, `3D tensor`).
* Executed standard arithmetic operations, distinct element-wise multiplications, and matrix dot products (`tf.matmul`).
* Demonstrated dimension transformation via `tf.reshape` and zero-copy interoperability with NumPy arrays.
* Evaluated trade-offs between TensorFlow, PyTorch, and Keras to inform framework selection across research and production workflows.
